# 數位實中　美術課 AI 眼鏡 App｜手機模擬原型

新竹五校 AI 眼鏡專案。這是**手機模擬的可點擊原型**，用來讓老師與工程師先走一遍流程。

👉 **線上試玩**：https://maktia.github.io/art-ai-glasses-app/

## 這是什麼

- 電腦打開是一支**模擬手機**，旁邊列出所有畫面，可以直接跳著看。
- 15 個畫面都做成網頁，按鈕可以按、可以一頁一頁走完。
- **沒有接後端、沒有接 AI**：照片、AI 的回話、學習單內容都是假資料。
- 手機開比較接近實際使用的樣子；電腦開會自動縮成一支手機的大小。

## 課程結構

一堂課只做一件事：

| 課別 | 動線 |
|---|---|
| 創作課 | 首頁 → 眼鏡連線 → 課程代碼 → 個人資料 → **邊畫邊聊** → 我的學習單・創作歷程 → 送出 |
| 賞析課 | 首頁 → 眼鏡連線 → 課程代碼 → 個人資料 → **看看這幅畫** → 我的學習單・作品賞析 → 送出 |

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 手機模擬器（從這裡進去） |
| `01-home.html` ～ `09-done.html` | 15 個畫面 |
| `flow-1.html` ～ `flow-4.html` | 頁面流程圖（16:9，簡報用） |
| `flow-5.html` | 操作流程圖（純方框、文字、箭頭） |
| `tasks.html` | 大題結構：每個大題要存到後端的資料 |

## 設計

- 主題色：黑石 `#3B3A38`，底色米白 `#F6F2EA`
- 活動配色：邊畫邊聊＝陶土紅 `#A4553A`、看看這幅畫＝靛藍 `#3E5E7E`
- 字型：標題 Noto Serif TC、內文 Noto Sans TC
- 畫面尺寸：412 × 917（學習單頁 412 × 1000）

畫面設計與流程圖同步自 Claude Design 畫布。

## 給工程師

- 每一頁都是獨立的靜態 HTML，沒有框架、沒有打包工具，直接開就能看。
- 實際要做的資料欄位看 `tasks.html`（大題結構）。
- App 跟後端交換什麼資料，另有一份說明文件（`美術課AI眼鏡App-ClaudeCode步驟流程.md`）。
